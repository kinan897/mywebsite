Football Match Predictor

A model that predicts win/draw/loss probabilities for top European football leagues — trained in Python, running entirely in your browser with no server behind it.

Python scikit-learn XGBoost Pandas NumPy JavaScript

Overview

A machine-learning site that estimates win, draw, and loss probabilities for matches in the Premier League, La Liga, Bundesliga, Serie A, Ligue 1, and the UEFA Champions League. The models are trained on 14,000+ matches since 2019, pulled from ESPN's public API, and the whole thing ships as a static site — the trained model runs client-side, so there's no backend making predictions on the fly.

Engineering Highlights

  • Time-aware features: 58 pre-match features — rolling form, an Elo rating, home advantage, rest days, a Champions League flag — each computed strictly from matches finished before kickoff, so the model never sees information it wouldn't have had in real time.
  • Two models, validated properly: a Random Forest and XGBoost, both tuned with time-series cross-validation rather than a random split, so training always respects chronological order instead of accidentally peeking into the future.
  • Zero backend: the trained Random Forest is exported to JSON and runs directly in the browser in plain JavaScript — a prediction happens entirely client-side.
  • Honest benchmarking: evaluated on 2,455 unseen matches, the Random Forest hits about 52.6% accuracy and XGBoost about 52.9% — both ahead of the always-predict-home-win baseline (45.0%), and roughly matching a pure Elo-rating model (52.8%), with real-world bookmakers typically landing around 53–55%.

Built With

Data pipeline and model training run on Python — pandas and NumPy for feature engineering, scikit-learn and XGBoost for the models themselves. The deployed site is plain HTML, CSS, and JavaScript with the exported model baked in, hosted on Netlify.

Built for learning — not betting advice.
