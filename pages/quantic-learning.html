Quantic Learning

A gamified STEM-tutoring app, built from the ground up for a real tutoring company — and the reason they hired me a second time.

FastAPI React Native TypeScript SQLAlchemy SymPy PostgreSQL

How This Started

Quantic Learning is a real tutoring company. I reached out to the owner on my own initiative and offered to design and build a website for him and his team — for free, with no obligation. He loved the result so much that he came back with a second, paid request: build the company a full learning app. I delivered that too, and he paid for the work. What started as a cold outreach turned into a client relationship and a production engineering project.

Overview

Quantic Learning is a mobile app that teaches Ontario high school and first-year university STEM courses through bite-sized, game-style lessons. Students work through a path of short lessons, earn XP, keep daily streaks, and get instant, step-by-step feedback on every answer — including typed math expressions like 3x^2 - 2sin(x), not just multiple choice. Every topic follows a three-lesson arc: Learn (one idea per card, with graphs and diagrams), Practice (quick questions that build the foundation), and Destroyer (hard, multi-step problems worth triple XP, required before the next topic unlocks).

Engineering Highlights

  • Server-authoritative grading: lesson content never includes the answers, and the server grades every attempt and calculates XP itself — the app has no way to send a fake score.
  • A custom math grader, safely: typed answers are tokenized and parsed into SymPy expressions by a hand-written recursive-descent parser — no eval on user input — and equivalent forms like 2(x+1) and 2x+2 are both accepted.
  • Real authentication: Argon2id password hashing, short-lived JWT access tokens, and rotating refresh tokens that detect theft — if a used refresh token is replayed, every device on that login chain is signed out.
  • Content as code: every lesson is YAML, validated at startup and in CI — ids, answer formats, and graph formulas are checked automatically on every push via GitHub Actions.
  • Cross-platform graphs: graphs are authored as formulas, sampled server-side, and rendered as SVG, so they look identical on iOS, Android, and the web.

Built With

A React Native (Expo + TypeScript) client ships to iOS, Android, and the web from one codebase, with TanStack Query and Zustand managing server data and session state. The backend is a FastAPI (Python) service with SQLAlchemy and Alembic migrations, running on SQLite in development and PostgreSQL in production. Math is rendered with KaTeX for real LaTeX on every platform, and the roadmap's next step is an AI tutor powered by the Claude API that explains a student's specific mistake.
