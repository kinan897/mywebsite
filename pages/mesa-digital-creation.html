React Firebase Instagram Insights Event Systems

Overview

As President of Digital Creation for MESA, I run the club's entire digital presence — the website members use to find and sign up for events, the system that checks them in when they arrive, and the Instagram and TikTok accounts that bring people through the door in the first place.

Impact

  • Club website: Designed and launched MESA's website using React and Firebase, centralizing event listings and sign-ups for 200+ members.
  • Automated check-in: Built a QR-code-based event RSVP and check-in system, cutting manual sign-in time by 70% across 8 events.
  • Content & growth: Produced 40+ graphics and short-form videos for Instagram and TikTok, growing followers by 35% (1,200 → 1,620) since September 2026.
  • Data-driven posting: Used Instagram Insights to track engagement and A/B test post timing, raising average post reach by 25%.

Built With

The club site runs on React with Firebase handling auth and event data, feeding directly into the QR check-in flow used at events. The content side runs on a steady posting and analytics loop through Instagram and TikTok, with Instagram Insights driving what gets posted and when.
