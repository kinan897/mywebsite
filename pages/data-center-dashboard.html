Data Center Management System

An Oracle-backed platform for tracking and managing data center hardware in real time, with a React dashboard on top.

Oracle SQL PL/SQL React Netlify

Overview

A simulated data center management platform for tracking servers, CPUs, GPUs, and sensors as a real data center operator would — real-time status updates, the ability to remove resources as infrastructure changes, and a dashboard to see it all at a glance.

How It Works

  • Data layer: An Oracle database with SQL and PL/SQL procedures modeling every server, CPU, GPU, and sensor, handling real-time status updates and resource removal.
  • Dashboard: A React dashboard, deployed on Netlify, surfacing the data center's current state at a glance.
  • Predictive queries: PL/SQL-driven queries track utilization trends and flag hardware likely to need attention before it fails.

Why I Built It

I wanted hands-on experience with the kind of enterprise database design and predictive monitoring that real data centers run on — not just a CRUD app, but a system that models real infrastructure constraints and tries to get ahead of failures instead of just reporting them after the fact.
