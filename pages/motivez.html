Motivez

A social discovery app for finding nearby places, events, and things to do

React Native Supabase PostgreSQL Team Project

Overview

Motivez is a social discovery app that helps students and young adults quickly find nearby places, events, and experiences based on their interests, friends, and location. Instead of scrolling through multiple separate apps, users swipe through personalized recommendations and instantly decide what to do — a blend of a swipe-based interface, map-based recommendations, and an event system, built around real social connections.

Core Features

  • Find Places: A Tinder-style swipe deck for discovering nearby cafes, restaurants, and hangout spots, with smart filters for distance, vibe, and category.
  • Motives (Events): Create and join public or private events, discover what's happening nearby, and see who else is attending before joining.
  • Profiles & Recommendations: A profile system showcasing interests and past activity, powering personalized suggestions based on user habits and friend connections.

Built With

A React Native (Expo) frontend for a smooth cross-platform mobile experience, backed by Node.js and Supabase Edge Functions, with a PostgreSQL database and Supabase Authentication. Built with a small team of friends.
